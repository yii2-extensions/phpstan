# Upgrade guide

For upgrades from 0.4.x to the 0.5 development line, follow the [migration guide](docs/migration.md#upgrading-to-050).
It covers PHPStan 2.3, Yii requirements, inferred type changes, removed extension APIs, static stubs and result caching.

Version 0.5.0 is under development; use documentation matching the installed tag or commit. See the
[installation guide](docs/installation.md#choose-a-version) before changing Composer constraints.
